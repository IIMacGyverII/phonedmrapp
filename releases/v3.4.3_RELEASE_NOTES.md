# DMRModHooks v3.4.3 Release Notes

## Release Date
June 15, 2026

## UI Fix — Caller ID / History Layout

Fixed overlapping caller ID and DMR History in the intercom border box.

- **Caller ID** now displays at the top of the info panel (green text)
- **DMR History** displays directly underneath the caller ID (no side-by-side overlap)
- Border box remains **250dp** — history may overlap the spectrum/VU bars when content is tall
- Caller ID clears on **RECEIVE_STOP** (no linger timer); history persists

Includes v3.4.2 fix: full **24-bit** caller DMR ID decode from `DigitalAudioMessage` body bytes `[1..3]`.

## Other

- Added `temp/` to `.gitignore` (local screenshots/artifacts)

## Installation

1. Download `DMRModHooks-v3.4.3.apk` from this release
2. Install: `adb install -r releases\DMRModHooks-v3.4.3.apk`
3. **Reboot the device** (required for LSPosed hook updates)
4. Verify module remains enabled in LSPosed Manager
