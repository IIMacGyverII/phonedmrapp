# DMRModHooks v3.4.2 Release Notes

## Release Date
June 12, 2026

## Bug Fixes

### Caller DMR ID displayed incorrectly on BrandMeister / high IDs

Incoming caller ID was truncated to 16 bits. Stations with DMR IDs above 65535 showed only the lower 16 bits (e.g. **3199587** displayed as **53859**).

**Fix:** `hookDigitalAudioHandler()` now reads the full **24-bit little-endian** caller ID from `DigitalAudioMessage` body bytes `[1..3]`:

```
dmrId = (body[3]<<16) | (body[2]<<8) | body[1]
```

This corrects caller display, contact name lookup, activity history, transcription logs, and recording filenames.

## Installation

1. Download `DMRModHooks-v3.4.2.apk` from this release
2. Install: `adb install -r releases\DMRModHooks-v3.4.2.apk`
3. **Reboot the device** (required — LSPosed loads hooks at boot)
4. Verify module remains enabled in LSPosed Manager
