# DMRModHooks v3.4.6 Release Notes

## Release Date
June 21, 2026

## TG List Import Fix

Fixes digital channels imported from OpenGD77 codeplugs that use a **TG List** instead of a named contact in the Contact column. Previously these imported with `txContact=0` and `contactType=Private (0)`, so channels would not TX until manually edited in the channel editor.

- When Contact and DMR ID columns are empty, **`DirectDatabaseImporter`** resolves TX from the **first TG ID** in the named TG List (import `TG_Lists.csv` before `Channels.csv`)
- Sets **Group (1)** contact type when a TX DMR ID is present but CSV left type as Private
- Falls back to `contact_database.contact_type` when the contact name is known

## Wide-Band Default (25 kHz)

New and imported channels now default to **wide band (25 kHz)** on both UHF and VHF frequencies.

- **Import** — Parses CSV bandwidth column (`25` / `12.5`); defaults to wide when empty (replaces incorrect frequency-based logic that set UHF to narrow)
- **Export** — Analog channels export actual bandwidth (`12.5` or `25`) in `DirectDatabaseExporter` and `CSVExporter`
- **In-app** — `ChannelData()` hook defaults new channels to wide; Narrow remains selectable in the channel editor

## Prior fixes included (v3.4.5)

- Digital import → double-slot mode (`channel_mode=4`)
- Squelch empty/`0%` → default `2`
- RadioID.net global DMR ID database + caller detail panel
- 24-bit caller DMR ID decode (v3.4.2)

## Installation

1. Download `DMRModHooks-v3.4.6.apk` from this release
2. Install: `adb install -r releases\DMRModHooks-v3.4.6.apk`
3. **Reboot the device** (required for LSPosed hook updates)
4. For full CSV restore: import **Contacts → TG_Lists → Channels → Zones → DTMF** in that order
5. Verify module remains enabled in LSPosed Manager
