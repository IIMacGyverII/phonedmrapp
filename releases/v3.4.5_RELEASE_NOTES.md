# DMRModHooks v3.4.5 Release Notes

## Release Date
June 16, 2026

## OpenGD77 CSV Import Fixes

Fixes two issues when importing an OpenGD77 codeplug CSV on the phone:

- **Double-slot mode** — Digital channels are now always imported as **Double slot** (`channel_mode=4`) with outbound slot matched to the imported timeslot. Previously, timeslot imported correctly but mode stayed **Direct** (0), so channels would not tune/RX.
- **Squelch default** — Empty, `None`, or `0%` squelch values now default to **2** (normal) instead of wide-open **0**.

## RadioID.net Global DMR ID Database

Offline lookup for unknown RX caller IDs using the official RadioID.net user database.

- **Download RadioID Database** — Device tab fetches `radioid.net/static/user.csv` (~17 MB, ~300k IDs)
- **Import RadioID CSV** — manual fallback from `Download/DMR/RadioID/` if download is unavailable
- **Separate SQLite cache** (`dmrmod_radioid.db`) — does not touch OEM `contact_database`
- **Two-tier lookup** — your codeplug contacts always win; global DB is fallback only
- Stores full CSV fields: callsign, first/last name, city, state, country
- Status line warns if DB has names only (re-download for location fields)

## RX Caller Detail Panel

Compact horizontal layout over the spectrum (semi-transparent):

- Large callsign headline with source badge (🌐 RadioID / ⭐ personal contact)
- Row: DMR ID + registrant name side by side
- Row: city · state · country on one line

## DMR History

History lines use full panel width with richer labels:

- Format: `First Last · CALLSIGN  HH:mm:ss 📻 Voice RX -XX dBm`
- Applies to live RX and reloaded channel history

## Bug Fixes

- Fixed crash (`BadTokenException`) when showing RadioID download progress dialog
- Progress dialog now uses Activity context with lifecycle checks

## Prior fixes included

- v3.4.2: 24-bit caller DMR ID decode
- v3.4.3: Caller/history panel layout in 250dp border box

## Installation

1. Download `DMRModHooks-v3.4.5.apk` from this release
2. Install: `adb install -r releases\DMRModHooks-v3.4.5.apk`
3. **Reboot the device** (required for LSPosed hook updates)
4. Device tab → **Download RadioID Database** (Wi‑Fi recommended, ~1–2 min first import)
5. Verify module remains enabled in LSPosed Manager
