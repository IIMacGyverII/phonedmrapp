# Back-check: strings_device.xml, strings_service.xml, strings_web.xml (ja)

Translated back to English without the source, compared meaning, negation, numbers and units, then fixed.

**Checked:** 1,340 strings (strings_device.xml 703, strings_service.xml 394, strings_web.xml 243). Placeholders,
`\n` and `\u0020` counted per string against English by script (all match, apart from the deliberate changes
below). `de_check.py`: 0 problems, 0 untranslated in all three files.

## Deliberate differences from English (not errors)
- service_caption_speaker: `%1$s：` with a full-width colon and no trailing `\u0020` (Japanese needs no space after ：).
- service_sched_day_sep: `、` instead of `,\u0020` (Japanese list comma, no space).
- device_radioapp_why_separator: `、` instead of `, `.
- Weekday abbreviations are one kanji (月 火 水 木 金 土 日), as the glossary says.
